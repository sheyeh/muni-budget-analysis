# Level 3: File Analysis Examples — Standardized Budget Line Items

This directory contains the production-ready Level 3 standardized budget line items (`line_items.json`) for each processed municipality, organized by municipal ID (`{muni_id}`).

These outputs are generated by the production Stage 3 pipeline (`src/muni_budget_analysis/analysis/run.py`), which performs upfront pre-filtering, concurrent asynchronous LLM calling (via the Gemini API), and structural-to-National standard schema classification and unit-normalization.

## Directory Structure

```
docs/examples/level3-analysis/
├── README.md
├── {muni_id}/
│   └── line_items.json       # Production-ready, standard-classified budget records
```

Each `{muni_id}/line_items.json` file conforms strictly to the schema definition specified in `docs/handshake-level3-postgres.md`.

## Pipeline Execution

To generate or re-analyze the line items from the Level 2/2.5 outputs (located under `docs/examples/level2-processing/`), run the following command from the repository root:

```bash
# Run Level 3 analysis over the example inputs, writing to the Level 3 output directory
.venv/Scripts/python -m muni_budget_analysis.analysis.run \
  --processed-dir docs/examples/level2-processing \
  --analysis-dir docs/examples/level3-analysis
```

## Input/Output Mapping

*   **Inputs**: Consumes `normalized.json` (Level 2 extraction) and `scoped.json` (Level 2.5 scope filtering) from `docs/examples/level2-processing/{muni_id}/`.
*   **Outputs**: Generates and writes `line_items.json` to the corresponding `docs/examples/level3-analysis/{muni_id}/` folder.
